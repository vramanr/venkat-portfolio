# Site Images

Save the two branded photos here with these exact filenames so they appear automatically on the site:

| Filename | Where it appears | Source image |
|---|---|---|
| `banner.jpg` | Featured section right under the hero (16:9 banner) | The "Ensure Software Quality Excellence" portrait |
| `innovatix.jpg` | Top of the Innovatix experience card (16:9 panel) | The handshake at Innovatix Technology Partners |

Notes:
- JPG, PNG, or WebP all work — but keep the `.jpg` extension if you can, since the HTML references `.jpg` (rename if needed).
- Recommended widths: ~1600 px for the featured banner, ~1400 px for the Innovatix card image. Larger is fine; the site will resize.
- If the files are missing, the site degrades gracefully — the featured banner shows a placeholder grid and the experience card shows a thin gradient bar.
